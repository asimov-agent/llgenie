# Data-modeling reference — FastAPI + SQLAlchemy 2.0 + Postgres

## Column type map

| SQLAlchemy | PostgreSQL | Use for |
|---|---|---|
| `BigInteger` | BIGINT | IDs (avoid overflow at scale) |
| `String(n)` | VARCHAR(n) | short text, always cap length |
| `Text` | TEXT | unbounded text |
| `Numeric(12,2)` | NUMERIC | money — exact, returns `Decimal` |
| `Boolean` | BOOLEAN | flags |
| `DateTime(timezone=True)` | TIMESTAMPTZ | timestamps — always tz-aware |
| `Date` | DATE | dates |
| `JSONB` | JSONB | flexible/hierarchical data |
| `Uuid` | UUID | distributed/system IDs |
| `ARRAY(String)` | TEXT[] | simple list fields |

## Canonical best-practice table class

```python
from datetime import datetime
from decimal import Decimal
from sqlalchemy import (String, Text, BigInteger, Numeric, Boolean,
                        DateTime, ForeignKey, func, Index, CheckConstraint)
from sqlalchemy.orm import Mapped, mapped_column, relationship
from .database import Base


class Product(Base):
    __tablename__ = "products"
    __table_args__ = (
        Index("uq_products_sku", "sku", unique=True),
        CheckConstraint("price >= 0", name="ck_products_price_nonneg"),
    )

    id: Mapped[int] = mapped_column(BigInteger, primary_key=True)
    sku: Mapped[str] = mapped_column(String(32), nullable=False)
    name: Mapped[str] = mapped_column(String(120), nullable=False)
    description: Mapped[str | None] = mapped_column(Text, nullable=True)
    price: Mapped[Decimal] = mapped_column(Numeric(12, 2), nullable=False, default=Decimal("0.00"))
    is_active: Mapped[bool] = mapped_column(Boolean, nullable=False, default=True)
    created_at: Mapped[datetime] = mapped_column(DateTime(timezone=True),
                                                 nullable=False, server_default=func.now())
    updated_at: Mapped[datetime] = mapped_column(DateTime(timezone=True),
                                                 nullable=False, server_default=func.now(),
                                                 onupdate=func.now())
    category_id: Mapped[int] = mapped_column(ForeignKey("categories.id", ondelete="RESTRICT"),
                                             nullable=False, index=True)
    category: Mapped["Category"] = relationship(back_populates="products")
```
