# Split nothing — fix the architecture bot's gh verb regression and ship the refresh it was owed (issue #2645)

## Why

The architecture bot's 2026-11-13 20:04Z run (run 43498203622, run #47) created issue #2645 and then died in its publish step:

```
architecture-bot: gh api PATCH repos/asimov-agent/llgenie/issues/2645 -F body=@- failed (1): accepts 1 arg(s), received 2
make: *** [mk/bots.mk:181: architecture-bot-publish] Error 2
```

`scripts/architecture_bot.py` issues the pre-PR acceptance tick with a POSITIONAL verb
(`gh api PATCH <endpoint>`). The runner gh moved to 2.103.3, which no longer accepts a positional
method plus endpoint for `gh api` — the form is now `gh api --method PATCH <endpoint>` (the form
`scripts/acceptance_writeback.py` already uses). Measured on this host with the same gh 2.103.3:
`gh api PATCH repos/…/issues/1 -F body=@-` → `accepts 1 arg(s), received 2`, while
`gh api --method PATCH` parses and dispatches. The fake-gh test fixture matched the broken form, so
no test could ever see the regression: run #46 (07:22Z) was green because it published nothing and
never reached the PATCH call.

The consequence is double: the bot cannot tick/file its refresh pair any more, and the refresh the
board is owed right now (`docs/ARCHITECTURE.md` lagging 9 commits / 126 paths at `63f717ad`) has no
PR — issue #2645 sits open with no branch.

## What Changes

- `scripts/architecture_bot.py` publishes the ticked issue body with
  `gh api --method PATCH <endpoint> -F body=@-` — the verb moves from argv position to the
  `--method` flag every gh ≥ 2.x accepts.
- `tests/test_architecture_bot.py`'s fake-gh and its call-order assertion lock the NEW call shape
  (`api --method PATCH …`), and a new assertion forbids the bot from ever reintroducing a
  positional verb in a `gh api` call — the regression becomes a test failure, not a CI outage.
- The refresh #2645 describes is shipped on this branch: `docs/ARCHITECTURE.md` regenerated by the
  bot's own sanctioned legs (`make architecture-bot-brief` then `make architecture-bot-doc`, Hermes
  inside the agent image), committed with the pair `check-docs` owes (agent-wiki note,
  `docs/changes.d/` row, `CHANGES.md`).

## Impact

- Affected specs: `architecture-doc` (ADDED: the gh call shape the publish leg must use).
- Affected code: `scripts/architecture_bot.py`, `tests/test_architecture_bot.py`,
  `docs/ARCHITECTURE.md` + its pair.
- The next scheduled architecture-bot run (6-hour cadence) publishes through the fixed call; a
  green run at a future head is forward-looking evidence, never a criterion claimed here.
