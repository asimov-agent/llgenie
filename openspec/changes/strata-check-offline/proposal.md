# Strata's model-map check goes hermetic — compare data to data, move the fetch to a named target

## Why

`make ci-unit` runs `make check-strata-models`, and that step leaves the machine every lane run.
Measured on `main` `76dd9bf13` (2026-11-19): `scripts/strata_models.py check` with no `--src` calls
`checkout()`, which shallow-fetches `https://github.com/Niko1221/Strata` at the pinned sha
`4a416016…`, then imports `setup.py` (723,971 bytes / 11,349 lines) from that clone. A GitHub hiccup
reds `ci-unit` while the tree is fine — the exact failure that opened #437 (`git fetch` exit 128,
"nine errors" on the macOS runner), reintroduced through this sibling step. Issue #519.

## What changes

- **The pinned source becomes a committed artifact.** `make sync-strata-models` vendors Strata's
  `setup.py` at the skill's pinned commit verbatim into `data/vendor/strata/setup.py` and writes a
  manifest `data/vendor/strata/manifest.json` (`url`, `ref`, `pinned`, `bytes`, `sha256`). The vendor
  is regenerated by sync, never hand-edited — the same "do not edit" rule as the json it feeds.
- **`make check-strata-models` (the ci-unit step) becomes hermetic.** It compares `data/strata_models.json`
  to `extract()` re-derived from the VENDORED `setup.py`, after asserting the vendor chain: the
  manifest's `pinned` equals the skill's `pinned`, and the vendored file's sha256 equals the
  manifest's. Zero network, zero git.
- **The live fetch survives as a named target.** `make check-strata-models-live` runs the old
  compare-against-upstream path (`check-live` subcommand); `make sync-strata-models` stays the only
  network writer. The decision is recorded here and in the make help lines — not a silent retry.
- **Bumps carry the vendor.** `engine_bump._sync_generated` already runs `make sync-strata-models`
  on every Strata bump, so the vendored file, manifest, and json regenerate together in the bump PR.

## Not a change

- `data/strata_models.json`'s content (the extraction transform is untouched).
- `scripts/ci_unit.py`'s step list and the pinned ci-unit sequence fixture (same target names).
- `tests/test_strata_download.py` and its roster `excluded` entry (#437's decision stands).
