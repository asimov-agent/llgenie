# hf-cli-pin: the CI hf downloader now installs the lock's version (closes #2380, PR #2625)

## What was verified

- The defect (#2380): engine-build's `hf CLI (tiny test model)` step ran an inline
  `uv tool install "huggingface_hub[cli]>=0.30"`; run 42558839616 resolved 2.4.0, whose
  `cli` extra was removed — every cell logged the missing-extra warning, and the step
  bypassed `tools/requirements.in`, which pins `1.30.0`.
- The fix: `make hf-cli-install` greps the exact `huggingface_hub==<pin>` line from
  `tools/requirements.in` and installs it; the workflow step runs only that target.
  Proved on this host in a disposable `UV_TOOL_DIR`: `make hf-cli-install` rc=0,
  `uv` resolved `huggingface-hub==1.30.0`, installed executables `hf, huggingface-cli,
  tiny-agents`, `hf --version` -> `1.30.0`.
- The extra itself was stale: even at the pinned 1.30.0 uv warned `does not have an
  extra named cli` (proved by the same run), so `tools/requirements.in` now pins
  `huggingface_hub==1.30.0` with no extra, and `make generate-requirements` recompiled
  `tools/requirements.txt` to `huggingface-hub==1.30.0` (rc=0).
- Lock test: `tests/test_requirements_pins.py::test_the_ci_hf_downloader_installs_the_pinned_spec_through_make`
  ties the step's `run: make hf-cli-install`, the target's grep-of-the-lock recipe, the
  absence of any `uv tool install` in the workflow, and the extra's absence from both
  compile files. Hermetic battery: 23 passed rc=0
  (`tests/test_requirements_pins.py tests/test_engine_build_workflow.py tests/test_targets_coverage.py`).

## Key decisions

- Route through make (AGENTS rule: every CI command is a make target) rather than just
  re-pinning the inline install — the target fails loudly if the lock line disappears.
- Drop `[cli]` from the compile input at the root: the extra no longer exists upstream;
  keeping it means AC2 ("no extra warning on a fresh dispatch") could never be ticked.
- `uv tool install` reads the spec verbatim from the lock line — one source of truth,
  no second version constant.
