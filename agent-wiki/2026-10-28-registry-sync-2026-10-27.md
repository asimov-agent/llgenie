# llgenie follows the `2026-10-27T21:47:11Z` trending store

The weekly `registry-sync` review for the store stamped `2026-10-27T21:47:11Z` (the review issue
this run was handed carried no number in `issue.md`; the dated-decision rule it applies is #229, and
the new-engine queue it defers to is #673/#686). Delivered on `main` through the sync-review PR.

## What was wrong

llgenie was still built to the previous store (`generated_utc` `2026-10-27T12:53:42Z`, 42 engines):
`data/models.json` was the old file, `data/engine-skill-gap.json` still counted 42 engines, the quant
table carried 1611 links and the trend-list matrix was rendered from the old row set. A store that has
moved while the product has not is yesterday's catalogue: new models are never offered, a new engine
stays unranked, and the goldens keep passing against rows upstream has replaced.

## Decisions taken

- **The store is re-vendored, not patched.** `make sync-registry` wrote `data/models.json` +
  `data/trending-README.md` at `2026-10-27T21:47:11Z` — 112 models (unchanged), **43** engines, the
  contract unchanged (no required key added or removed, no new `backend`).
- **Every derived table is regenerated by its generator**, never hand-edited: the quant catalog
  (89 models / **1661** links; the live-Hub probe validated 0 newly-added links and gated 0),
  the trend-list matrix (**81** cases) and the engine-skill gap.
- **`Rapid-MLX`, the one engine new to the store, is decided rather than carried silently.** Its
  upstream README scopes it to Apple Silicon (`brew install rapid-mlx`, pure MLX kernels, no Linux or
  GGUF path) and the product is a macOS desktop app plus image/video/audio aliases; Metal cannot run
  in llgenie's Linux image and that platform is already served natively by the `mlx` engine. So it is
  a dated `deferred` entry in `data/unsupported-engines.json`, with the upstream URL it was read from
  — the shape the five earlier Apple-Silicon-only servers (`mlx-serve`, `oMLX`, `MTPLX`, `Slotstream`,
  `Kapitsa`) already use. Not shipped, not silently dropped.
