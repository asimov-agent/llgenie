# The vision is a page the README links

Issue: #1349.

The README already says llgenie ranks engines from the trending-local-llms list against this card and serves the quant that fits. It did not say, in one place, that the experience is a person loading a trending local model on the inference server they chose, fitted to the hardware, with the highest measured tokens per second among the servers that fit.

`docs/VISION.md` says that. The fit it names is the one in `scripts/detect_server.py`: card RAM, Prism at 24 GB and below, upstream above that, backend Metal, CUDA, or CPU. A tokens-per-second figure that was not measured is not a claim. The README user-guide table links the page.

This pull request does not change the ranker. Measuring tokens per second in the picker is a later change.
